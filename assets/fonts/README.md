# Fonts

Bundled in the program, all under the SIL Open Font License 1.1 (the licence text of each one sits next to it):

- **IBM Plex Mono**: the text of the interface (`IBMPlexMono-Regular.ttf`, `IBMPlexMono-Bold.ttf`).
- **Cinzel**: the title, Roman inscription capitals (`Cinzel-VF.ttf`, variable weight).
- **Noto Sans Old Italic**: the Etruscan letters (`NotoSansOldItalic-Regular.ttf`).
